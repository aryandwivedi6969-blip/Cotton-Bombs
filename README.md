# Cotton Bombs — Full Stack E-Commerce

Cotton Bombs is a modern, high-energy e-commerce experience built with a React (Vite) frontend and a Python (FastAPI + Supabase) backend.

## 🚀 Quick Start

### Frontend (React + Vite)
```bash
cd frontend
npm install
npm run dev
```

### Backend (FastAPI)
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

## 🛠️ Deployment Configuration

This repository includes root configuration files (`package.json`, `netlify.toml`, `vercel.json`) to support automated continuous deployment on platforms like Netlify, Vercel, and Cloudflare Pages.
